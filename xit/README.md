# XIT paper page

Static project page for the T-RO paper. `index.html` + `assets/`, no build step.
Preview: open `index.html` in a browser.

## Deploying
Either
- copy this folder into `malfazliu-site/xit/` (served at https://malfazliu.com/xit/ once that site is live), or
- put it in the public XIT code repository under `docs/` and enable GitHub Pages on that folder.
